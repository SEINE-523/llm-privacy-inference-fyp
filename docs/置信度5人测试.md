# confidence 1–5 五人样本测试

- 日期：2026-11-08
- 模型：DeepSeek `deepseek-flash`
- 样本：`pers107`、`pers121`、`pers193`、`pers20`、`pers226`（前 5 个人物）
- 输入：每人全部文本
- 规模：5 次真实请求/组
- 新机制：每个属性先输出 `confidence`（1–5），再决定是否 `abstain`

---

## 1. 机制

每个属性输出：

```json
{
  "confidence": 1,
  "guesses": [],
  "evidence_ids": [],
  "reason": "...",
  "abstain": true
}
```

- `confidence = 1`：弃答（`abstain=true`，不给猜测）；
- `confidence = 2–5`：必须给猜测（`abstain=false`）。

代码默认阈值已改为 **1**，可通过 `--confidence-threshold` 调整；解析器会强制执行阈值，而不是完全依赖模型自觉。

---

## 2. 三组对比（同样 5 人）

| 方案 | Top-1 | Top-3 | 弃答数 |
|---|---:|---:|---:|
| 旧 baseline（无 confidence） | 15/45 = 33.3% | 20/45 = 44.4% | 21/45 |
| confidence 阈值 2（1–2 弃答） | 13/45 = 28.9% | 18/45 = 40.0% | 26/45 |
| **confidence 阈值 1（仅 1 弃答）** | **18/45 = 40.0%** | **23/45 = 51.1%** | **18/45** |

阈值 1 相对旧 baseline：

- Top-1：+3 例（33.3% → 40.0%）；
- Top-3：+3 例（44.4% → 51.1%）；
- 弃答：-3 例（21 → 18）。

阈值 2 反而更差：模型给 age 的置信度普遍是 2，被强制弃答，丢掉了 baseline 原本能猜对的 3 例。

---

## 6. 结论与建议

1. **加入 confidence 本身不会自动降低弃答率**；关键在阈值。
2. **阈值 2 太严**：age/sex 这类“低置信但仍有线索”的属性被强制弃答，结果反而变差。
3. **阈值 1 更合适**：只把 confidence=1（几乎无信息）判为弃答，Top-1/Top-3 都优于旧 baseline，弃答减少。
4. 5 人样本很小，当前结论只用于定方向；**随后已在全部 11 人上复测阈值 1**。
5. 已修复一个解析问题：模型偶尔重复输出同一个 guess（如 `Accountant` 三次），现在会去重而不是整条报错。
